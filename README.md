# weather-time-widget
HTML/CSS/JS weather and time widget for OBS Studio

**Features**
- Real-time clock updates every second
- Weather updates every 10 minutes
- Automatic weather icons based on conditions

**Requirements**
1. OBS Studio
  - Download: https://obsproject.com
2. OpenWeather API Key
  - Free account available at: https://openweathermap.org/api
3. Text Editor (VS Code, etc)

**Installation Guide**
1. Download the widget
2. Get an Openweather API Key
3. Add your API key
4. Change your city
5. Add your widget to OBS via sources -> Local File
